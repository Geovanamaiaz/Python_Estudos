# Python Básico — Códigos Comentados

Este repositório reúne exemplos introdutórios de Python, com comentários em português para explicar cada parte do código.

## Conteúdo

1. `01_variaveis.py` — variáveis
2. `02_tipos_de_dados.py` — tipos de dados
3. `03_operadores.py` — operadores matemáticos
4. `04_input_e_conversao.py` — entrada de dados e conversão
5. `05_calculo_com_float.py` — cálculo de média
6. `06_if_else.py` — condições `if` e `else`
7. `07_if_elif_else.py` — condições `if`, `elif` e `else`
8. `08_for_range.py` — repetição com `for` e `range`
9. `09_while.py` — repetição com `while`
10. `10_listas.py` — listas
11. `11_funcoes.py` — funções
12. `12_projeto_media.py` — mini projeto: média do estudante

## Como executar

Com Python 3 instalado, abra o terminal na pasta do projeto e execute, por exemplo:

```bash
python3 01_variaveis.py
```

Para executar outro módulo, troque o nome do arquivo.

## Objetivo

Praticar fundamentos de Python com exemplos pequenos e comentados. Os arquivos são independentes e podem ser executados separadamente.
